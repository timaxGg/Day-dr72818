# Day-Trader

App + Bot für kurze Trades (Long und Short) mit Faktor-Zertifikaten bei Trade Republic – mit echten Kursen, nachgerechneten Trefferquoten, Verkaufshilfe und Telegram-Warnungen.

- App: https://timaxgg.github.io/Day-dr72818/ (`index.html`, `app.js`, `kern.js`)
- Bot: `bot/daytrader.mjs` – auf dem Handy/Server (`start.sh`) oder als Backup über GitHub Actions (`.github/workflows/wache.yml`)
- Daten: Zweig `daten` (day.json, zeiten.json, verlauf.json, faelle.json, tage.json, log.json)
- Einrichtung: [ANLEITUNG.md](ANLEITUNG.md)

Keine Anlageberatung.
